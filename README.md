#SwiftMart – React E-Commerce UI
A clean and responsive e-commerce frontend built with React and Bootstrap. Perfect for showcasing frontend skills with modern React.

##Features
Product Listing & Search: Browse and search through a list of products.
Add to Cart with Toasts: Add products to the cart with visual feedback using toasts.
Dark Mode Toggle: Switch between light and dark modes for a better user experience.
Cart Saved in LocalStorage: Persist the cart data in local storage to retain user selections.
Mobile-Friendly Design: Responsive design that works well on mobile devices.

##Installation
Clone the repository:
git clone https://github.com/your-username/swiftmart.git

Navigate to the project directory:
cd swiftmart

Install the dependencies:
npm install

Start the development server:
npm start

Open your browser and visit http://localhost:3000 to see the app in action.

##Usage
Product Listing & Search: Use the search bar to filter products.
Add to Cart: Click the "Add to Cart" button on any product to add it to your cart.
Dark Mode Toggle: Use the toggle switch to switch between light and dark modes.
Cart Management: View and manage your cart items. The cart data is saved in local storage.

##Technologies Used
React: A JavaScript library for building user interfaces.
Bootstrap: A popular CSS framework for developing responsive and mobile-first websites.
LocalStorage: Web storage to persist cart data.
